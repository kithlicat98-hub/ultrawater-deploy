How It Works

Three steps. Under two minutes.

Python and everything else is bundled inside the download. Java is handled by the wizard. You do nothing except click Next.

1

Download the launcher

Pick your OS below. The file already contains Python, all libraries, and everything UltraWater needs. No other installs required.

2

Run the setup wizard

On first launch a wizard opens. It auto-detects Java (or downloads it), lets you set RAM and a game folder. Takes about 45 seconds.

3

Press Launch → play

Select your Minecraft version, hit Launch. UltraWater downloads the game if needed, applies FPS optimisations, and opens it.

FPS Optimizer

Aikar's JVM flags applied on every launch automatically. Most players gain 30–80% FPS on vanilla. Add Sodium + Lithium for up to 3× gains.

Mod Manager

Drag-and-drop .jar mods with per-profile isolation. Supports Fabric, Forge, Quilt, and NeoForge with one-click loader install.

Add .zip shader packs and swap between them instantly. Works with OptiFine and Iris Shaders. Each profile keeps its own active shader.
